# Rangoon.Tech English Fonts

## Sora — Titles and Headings

Use Sora for:

- Titles
- Headings
- Section headers
- Key statistics
- Short impact statements

Recommended files:

- `Sora-Bold.ttf`
- `Sora-SemiBold.ttf`
- `Sora-Medium.ttf`
- `Sora-Regular.ttf`

## Poppins — Body and Supporting Text

Use Poppins for:

- Subtitles
- Subheadings
- Body copy
- Quotes
- Captions
- Supporting information

Recommended files:

- `Poppins-SemiBold.ttf`
- `Poppins-Medium.ttf`
- `Poppins-Regular.ttf`
- `Poppins-Italic.ttf`

## Canva Font Settings

- **Title:** Sora Bold
- **Subtitle:** Poppins Medium
- **Heading:** Sora SemiBold
- **Subheading:** Poppins Medium
- **Section header:** Sora SemiBold
- **Body:** Poppins Regular
- **Quote:** Poppins Medium Italic
- **Caption:** Poppins Regular

## Usage Rules

- Use only Sora and Poppins.
- Use no more than two font families in one design.
- Avoid Thin and ExtraLight weights for normal content.
- Use static font files in Canva instead of variable fonts.
- Keep headlines short and body text easy to read.
