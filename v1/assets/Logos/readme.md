# Rangoon.Tech Logos

## Logo Files

- `rtx-primary-logo-full-color-horizontal-light.png`
  Default logo for white and light backgrounds.

- `rtx-secondary-logo-full-color-stacked-light.png`
  Compact logo for vertical or limited spaces.

- `rtx-logo-white-horizontal-dark.png`
  Use on dark backgrounds.

- `rtx-logo-dark-horizontal-light.png`
  Use on white or light backgrounds.

- `rtx-wordmark-mint-teal-transparent.png`
  Teal wordmark without the Burst Brand Mark.

- `rtx-wordmark-white-dark.png`
  White wordmark for dark backgrounds.

- `rtx-wordmark-dark-light.png`
  Dark wordmark for light backgrounds.

- `rtx-burst-mark-full-color-gradient-transparent.png`
  Default standalone brand symbol.

- `rtx-burst-mark-square-social-profile.svg`
  Square profile icon.

- `rtx-burst-mark-circle-social-profile.svg`
  Circular profile icon.

## Usage Rules

- Use the Primary Logo whenever possible.
- Use the Burst Brand Mark for icons and small spaces.
- Do not stretch, rotate, recolor, rearrange, or add effects.
- Maintain clear space around all logo assets.
- Use only the approved files in this folder.
