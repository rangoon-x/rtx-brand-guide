# Rangoon.Tech Burmese Fonts

## Brand Typography

### Masterpiece Daung Round — Titles

Use `MasterpieceDaungRound.ttf` for:

- Titles
- Headings
- Section headers
- Short impact statements

### Masterpiece Uni Sans — Body

Use `MasterpieceUniSans.ttf` for:

- Subtitles
- Body copy
- Quotes
- Captions
- Supporting information

## Logo Source Fonts

- `OT04_Blox.ttf` was used for the Burmese logo title “ရန်ကွန်းတက်”.
- `OT21_TwelLet-Regular.ttf` was used for the Burmese logo supporting text "ဆန်းပြားတဲ့ ဘရန်းအတွေ့အကြုံ".
- These fonts are retained for logo reference and recovery only.
- Do not use OT04 or OT21 in normal brand designs.
- Always use the approved exported logo artwork instead of recreating the logo with live text.
